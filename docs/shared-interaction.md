# Operator and system share the interface

In project work, an operator and an AI system need to understand the same
subject and participate through available sources, tools and actions. K-UX-AI
gives the assistant the knowledge and method to form the interface for that
relationship. [Italiano](shared-interaction.it.md).

## Reciprocal and simultaneous participation

The operator uses the interface to understand work, guide the AI, act and
correct. The system uses it to make information, changes and proposals
understandable through text, images, motion and tools. Both activities can
take place at the same time while retaining the same work context.

For example, the operator can continue writing in one card while another
receives an AI reply or shows a relevant change. The interface preserves the
subject, focus and drafts. The [card guide](public-griglia.md) explains the
current workspace; the [competence](../competences/ux-ai/COMPETENCE.md) and
[construction guide](../competences/ux-ai/GUIDE.md) carry its method.

Simultaneity concerns participation in the same ongoing work. Local feedback,
rendering, calculation and model-assisted understanding can have different
timings. Real-time visual output does not require a new model decision for
every frame. The receiving environment supplies its models, tools and sources;
the domain retains authority over actual work actions.

## A perceptual horizon beyond the screen

Glasses capable of displaying interactive video in real time could extend
this relation into what a person sees and does. Information, diagrams and
tools could appear alongside the observed subject and change with gaze,
voice or gestures. Such an experience could make details, relationships and
changes more perceptible during work.

This is a development direction, with no selected device or promised release.
The current demo uses cards, tools and dialogue. Spatial alignment, available
input channels and access to appropriate sources belong to the actual
receiving environment. The [Manifesto](../MANIFESTO.md) preserves the open
horizon across websites, applications and other expressive surfaces.

K-UX-AI remains a neutral competence kernel. A shipyard can express this
relation through vessel configuration, drawings, revisions and observations;
another domain supplies its own subjects and terminology.
