Come usare questo artefatto

Crea diagrammi e presentazioni modificabili. Usa lo stesso file per lavorare con la tua AI e comunicare le idee alle persone.

1 · Parti da un'idea

Scrivi o modifica riquadri, relazioni, note e schede. I template sono punti di partenza, non regole.

2 · Continua con un assistente AI

Salva l'HTML e allegalo a ChatGPT o a un altro assistente AI. Chiedi una revisione dei testi, una nuova organizzazione o un diagramma più chiaro. Puoi sempre correggere il risultato.

3 · Presenta e condividi

Usa Presenta con gli interlocutori. Salva lavoro mantiene note e strumenti; Copia pubblica esclude note e libreria. Verifica il file ricevuto prima di inviarlo.

4 · Layout e modifica

Premi Flat per sfruttare tutta la larghezza disponibile e disporre la lettura su due colonne nei monitor ampi. Apri Strumenti e trascina il bordo per ridimensionare; in Finestra mobile usa l’angolo in basso a destra. Quando modifichi un elemento compare il menu OK / Indietro / Avanti: OK conserva la modifica ed esce dall’editor.

Altri modi per usarlo

Progettare un prodotto, spiegare un sistema complesso, confrontare alternative, strutturare contenuti web, preparare un incontro o raccogliere correzioni successive. Lo stesso oggetto può cambiare rappresentazione senza perdere le relazioni.

Ritorno dall'AI: apri Strumenti → Salva ed esporta → Dati per AI. Invia il JSON al modello e chiedigli di restituire un JSON con lo stesso schema. Poi usa Importa JSON / HTML per rientrare nel lavoro. Puoi anche ricevere un intero HTML MetaCanvas: l'importatore recupera soltanto i dati e non esegue codice del file ricevuto. Controlla sempre le modifiche proposte.

Il file funziona offline e non contiene un assistente AI incorporato. Il modello partecipa soltanto quando gli alleghi il documento. Salva una copia di lavoro prima di inviarlo e controlla gli appunti: un file HTML può essere ispezionato da chi lo riceve.
